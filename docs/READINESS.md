# 公開準備状況と既知の制約

この文書は、`kroki-security-build-recipe`を公開する際の判断基準と、現時点で未検証または未評価の事項を一か所に整理するためのものです。

## 現在の公開スコープ

このリポジトリが提供するのは、**Linux AMD64向けの非公式Krokiセキュリティ更新ビルドレシピ**です。

- ビルド済みコンテナイメージ、JAR、D2/Goatバイナリは配布しません。
- Kroki 0.34.0を基点に、Java、Kroki JAR、D2、Goatと関連依存を更新します。
- 最終イメージは開発用パッケージを除去し、フラット化します。
- 安全性、全描画形式、全アーキテクチャ、完全な再現可能性を保証するものではありません。

このスコープを維持する限り、下記の未検証事項は公開時に明示する既知制約として扱います。

## 公開ブロッカー

**現時点で、既知の技術的な公開ブロッカーはありません。**

ただし、次の条件を外す場合は追加検証が必要です。

- Linux AMD64以外を「対応済み」と表明する場合。
- 全描画形式の動作を「検証済み」と表明する場合。
- 残存CVEを「安全」「影響なし」「受容済み」と表明する場合。
- 同一イメージの決定論的・再現可能な生成を保証する場合。
- ビルド済みイメージやバイナリを配布する場合。

Public化そのものとは別に、公開直前にはREADME、ライセンス、秘密情報・生成物の混入、Draft PRの最終差分をHumanが確認します。

## 既知制約として許容する事項

### ARM64は未検証

統合手順と実機検証はLinux AMD64で行っています。ARM64は未検証であり、現時点ではサポート対象として表明しません。

### 全描画形式の実動作は未検証

`/health`、PlantUML、D2、GoatのSVG変換はPASSしています。

また、元イメージにある`KROKI_*_BIN_PATH`の17パスについて実行可能であることを確認し、主要な描画プログラム、Kroki JAR、Goat、設定ファイルの保持も確認しています。

ただし、これは全描画形式のE2E変換試験ではありません。未試験の形式について動作保証はしません。

### キャッシュなし新規環境での一括ビルドは未検証

正式な統合ビルドは成功していますが、確認時はBuildKitキャッシュが利用され、MavenやD2の一部検証ステージはキャッシュから再利用されました。

Dockerfileにはソースタグ・コミットSHA照合、パッチ適用確認、Maven `clean verify`、D2 `go mod verify` / `go test ./...`を維持していますが、完全に空のDockerキャッシュから全ステージを通した実機確認は未実施です。

そのため「再現可能な手順」を提供しますが、完全なhermetic buildやbit-for-bit reproducibilityは保証しません。

### 残存178件のCVEは個別評価していない

2026-11-05のTrivy 0.76.1による全重大度検査では、Ubuntu 24.04にMEDIUM 98件、LOW 80件が残っています。UNKNOWN / HIGH / CRITICALは0件でした。

Kroki JAR、D2、Goatでは同検査時点で検出0件です。修正版ありHIGH/CRITICALの検査も0件、終了コード0でした。

残る178件について、攻撃到達可能性、誤検出、実運用上の影響、Risk受容の個別判断は行っていません。「HIGH/CRITICALが0件」を「脆弱性がない」または「安全性を保証する」とは扱いません。

### フラット化は来歴情報を保持しない

`docker export/import`によるフラット化では、元イメージのレイヤー履歴、ビルド由来のattestation、署名を保持しません。

一方、対応するEnv、Entrypoint、Cmd、User、WorkingDir、ExposedPorts、Labels、StopSignalは復元後に照合します。保持を保証できない設定が存在する場合は処理を失敗させます。

### 同一イメージIDの再生成は保証しない

APTの`upgrade`は実行時点のUbuntuリポジトリ状態に依存し、すべてのビルド用ベースイメージをDigest固定しているわけではありません。また、export/importの実行日時等もイメージIDへ影響し得ます。

したがって、同じソースから常に同じイメージIDが生成されることは保証しません。

### Mermaid補助コンテナは対象外

Mermaidは上流の別コンテナを必要とする構成のため、このリポジトリの初期検証・配布対象には含めません。

## 将来対応候補

優先度は公開後の利用状況と上流更新に応じて判断します。

1. キャッシュを無効化した新規環境での完全ビルド試験。
2. 主要なKroki描画形式を対象にしたE2E回帰テストの拡充。
3. ARM64ビルドと実機またはCI検証。
4. 残存MEDIUM / LOW CVEの個別トリアージと記録。
5. Maven、Go、Java等のビルド用ベースイメージのDigest固定範囲拡大。
6. APT更新を含む再現性・hermeticityの改善。
7. Mermaid補助コンテナを追加する場合の独立した脆弱性検査と通信・描画試験。
