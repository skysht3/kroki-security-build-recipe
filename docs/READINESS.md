# 対応範囲と既知の制約

このリポジトリはLinux AMD64向けの非公式ビルドレシピです。ビルド済みコンテナ・JAR・バイナリは配布しません。継続的な保守や安全性は保証しません。

- 現行の構成・検証状況は[0.37.1の検証記録](VALIDATION_2026-11-26.md)を参照してください。0.34.0のスキャン件数やイメージサイズは現行版へ引き継ぎません。
- ARM64、全描画形式、Mermaidなどの補助コンテナは未検証です。
- 公式イメージのDigestとソースSHAを固定しますが、ビルド用イメージやすべての取得物をDigest固定する構成ではありません。同一イメージIDの再生成は保証しません。
- 公式コンテナのUbuntu 26.04と、ホスト側のWSL Ubuntuは別です。実際の導入先で、Dockerの動作、設定、必要な描画形式とフォントを確認してください。
- 組織で採用する場合は、更新候補そのもののDockerビルド・スモーク試験・脆弱性検査と、切り戻し準備を完了してください。[更新ガイド](UPDATE_GUIDE.md)
